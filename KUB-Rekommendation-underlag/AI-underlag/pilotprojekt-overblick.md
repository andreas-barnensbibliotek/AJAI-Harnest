Här är ett underlag för att skapa ett pilotprojekt för KUB kulturarv bevarande. Tanken med projektet är att testa om systemet RODA som används i BGR och KSDs projekt CESAR, hur det kan användas för att långtidsbevara förvaltningens digitala kulturarv, de samlingar som vi har på museerna idag. I projektet så behövs det sättas upp en RODA-server där vi kan installera open source-programmet RODA för att kunna hantera själva bevarandet och koppla det mot de standarder som finns: OAIS, Dublin Core med mera. Vi behöver också testa med en klientapplikation som RODA-in, som är ett programvara som man kopplar till RODA-systemet. Det är en del, den tekniska delen, som vi behöver hjälp med från KSD, Kulturstad Digitalisering, att vi ska försöka få pengar från deras anslag, det är att vi får pengar från deras projekt, att sätta upp en virtuell server, en server som vi kan använda för att installera de här programvarorna så att vi får full åtkomst till det. Vi behöver också prata med KSDs lagringsenhet och infrastrukturenheten för att kunna få en lagringsyta i de datacenter som finns i VGR för att vi ska kunna koppla det systemet mot en säker lagringsplats. Så den tekniska planen behöver vi sätta upp i det här pilotprojektet. Vi behöver också ha ett parallellt spår där verksamheten arbetar fram ett arbetssätt för hur de ska hantera objekt och det som finns i samlingarna. Så att de har en plan för vad det är som ska långtidslagras i de digitala samlingarna. Vi behöver ha en gallringsstrategi. Vi behöver ha en förvaltningsplan, en samlingsförvaltningsplan som vi kan utgå ifrån. Och vi behöver också då i det parallella spåret titta på arbetssätten, att vi som ett första steg använder det arbetssättet som redan finns när det gäller Primus, som är ett förvaltningssystem för samlingsförvaltningssystem som redan används, där personalen och verksamheten lägger in objekt som ska långtidslagras eller som ska bevaras i systemet Primus, och där de redan jobbar med att tagga de här objekten med metadata som behövs och som vi också då skulle kunna använda i vårt långtidsbevarande. Det vi måste titta på är hur man kan exportera den här datan från Primus till RODA. Så det är en del av det projektet att titta på arbetssättet och också se hur man kan exportera datat och vilka standarder som ska gälla för verksamheten. Vi har en plan på att titta på om det går att anställa en, alltså projektanställa en projektledare för verksamhetens projekt som kan driva det. Och att vi då kanske kan få medel från KSDs bevarandeprojekt för att få hjälp att kunna anställa en sådan projektledare. Tanken är att vi ska använda oss av ett av de mindre museerna för att testa arbetssättet i pilotprojektet. Att vi följer hela kedjan från att verksamheten lägger till objekt i Primus och taggar dem med metadata och därifrån kan exportera det till RODA enligt de standarder som finns, till att använda RODA-in som ingest-program för att skicka datat till RODAs systemet, som då paketerar datat med ett ISP till ett AIP enligt IOAS-standarden. Och att det sedan när det har gått igenom RODA också hamnar på en rätt lagringsyta och lagras i paket som de ska. Så hela den kedjan vill vi följa i pilotprojektet för att se om det är ett bra arbetssätt och att paketen går att hantera enligt de standarder som finns, att det är ett bra arbetssätt och en långsiktig lagring för våra museer.
